My solutions to LeetCode problems, written mostly in **C++** (plus a few in SQL), by
[Siddharth Patel](https://github.com/exotic-Siddharth), B.Tech + M.Tech CSE at NIT Patna.

## How it's organised

Each problem has its own folder, named by problem number and title (for example
`0001-two-sum/`). Inside are:

- the solution file (`.cpp` or `.sql`)
- `README.md` with the problem statement and its difficulty

## Topics covered

Arrays and hashing, two pointers, sliding window, binary search, stacks and queues,
linked lists, trees and BSTs, heaps, graphs (BFS, DFS, shortest paths, union-find),
backtracking, greedy, dynamic programming, bit manipulation and SQL.
